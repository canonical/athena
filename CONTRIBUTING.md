# Contributing

Thanks for your interest in contributing to Athena.

## Before you start

- Read [README.md](./README.md) for project setup.
- Read [AGENTS.md](./AGENTS.md) for repository workflow guidance.
- Follow coding and documentation standards under [docs](./docs).

## Development workflow

1. Fork the repository and create a branch from main.
2. Install dependencies with npm install.
3. Make focused changes with clear commit messages.
4. Run checks locally with npm run check.
5. Run the tests locally using npm run test:ci
6. Open a pull request with a clear summary and QA notes.

## Pull request expectations

- Keep changes scoped and reviewable.
- Update docs when behavior changes.
- Include tests or rationale when tests are not updated.
