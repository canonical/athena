# Interaction Protocol

The engineering manager persona is a required participant in every loop and serves as the ultimate resolver of blockers and ownership ambiguity.

1. The engineering manager persona routes work and resolves who should act next when ownership is unclear.
2. The user is the approval authority for scope and content changes unless a definition states otherwise.
3. Only one persona should actively own a piece of work (event) at a time.
4. Every persona-to-persona transition must use the handoff definition.
5. When a persona is blocked by ambiguity, dependency, or missing approval, it performs a blocked handoff back to the engineering manager persona using the blocked handoff protocol in handoff.definition.md.
6. Discussions should stay attached to the active work context whenever possible.
