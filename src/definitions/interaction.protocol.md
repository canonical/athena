# Interaction Protocol

1. The engineering manager persona routes work and resolves who should act next when ownership is unclear.
2. The user is the approval authority for scope and content changes unless a definition states otherwise.
3. Only one persona should actively own a Jira item at a time.
4. Every persona-to-persona transition must use the handoff definition.
5. When a persona is blocked by ambiguity, dependency, or missing approval, it routes back through the engineering manager persona.
6. Discussions should stay attached to the active Jira item or its direct parent whenever possible.
